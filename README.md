# 鼠鼠警官Mod

RimWorld 1.6 / Ratkin 装备 Mod。

## 内容
- 民警：执勤服、秋冬服、警察背心、大檐帽、执勤帽
- 辅警：执勤服、秋冬服、反光衣、执勤帽
- 特警：执勤服、秋冬服、战术背心、贝雷帽
- 通用：甩棍执勤腰带、配枪执勤腰带、执法记录仪与肩灯
- 肩章：继承 CPOLICE 当前命名体系，8 级辅警 + 13 级警衔，共 21 套

## 依赖
- Ratkin / NewRatkinPlus (Solaris.RatkinRaceMod)
- Humanoid Alien Races（如果你的 Ratkin 版本需要）

## 说明
这是精简装备版，不包含交警、武器、派系、研究树、自动岗位系统或 CPOLICE DLL。
肩章 DefName 使用 MMP_ 前缀，避免与 CPOLICE 同时启用时冲突。
贴图按 Ratkin GreatWar 的 512x512 / Thin 方向结构制作。
